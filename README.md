# Проект для курсовой работы

## Приложение для получения и анализа данных о самолётах, находящихся в воздушном пространстве выбранных стран.

---

## Описание проекта

Программа позволяет:

- получить координаты стран через API Nominatim,
- получить данные о самолётах через OpenSky API,
- сохранить данные в базу данных PostgreSQL,
- выполнить анализ данных с помощью SQL-запросов.

Результаты выводятся в консоль.

***Данные о самолётах являются динамическими и зависят от текущего времени запроса к API.***


---

## Структура проекта

Проект разделён на логические модули:

- `src/config.py` — настройки подключения к базе данных  
- `src/api/nominatim.py` — работа с API координат стран  
- `src/api/opensky.py` — получение данных о самолётах  
- `src/api/db_manager.py` — работа с PostgreSQL  
- `main.py` — точка входа в приложение  

---

## Как запустить

Убедитесь, что у вас установлен Poetry. Если нет — установите его.

В терминале перейдите в корневую папку проекта:

    poetry install

 **Настройка окружения**

Создайте файл .env на основе .env.example и укажите свои данные:

- DB_NAME=airplanes
- DB_USER=postgres
- DB_PASSWORD=your_password
- DB_HOST=localhost
- DB_PORT=5432

**Запуск приложения**

    poetry run python main.py

### Что делает программа

- Создаёт базу данных (если её нет)
- Очищает таблицы
- Загружает данные по 10 странам
- Сохраняет информацию о самолётах в PostgreSQL
- Выполняет аналитические запросы:
  - количество самолётов по странам
  - средняя скорость
  - самолёты быстрее средней
  - поиск по callsign

### Особенности

  - Обработка ошибок API
  - Фильтрация некорректных данных
  - Исключение дубликатов (UNIQUE + ON CONFLICT)
  - Использование SQL-запросов для анализа данных

### Используемые технологии
  - Python
  - Poetry
  - PostgreSQL
  - psycopg
  - requests
